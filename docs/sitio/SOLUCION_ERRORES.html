Solución de errores comunes

SíntomaComprobarCorrección segura
Login no abre KeycloakEstado Docker, puerto/issuer públicoArrancar contenedores existentes; no cambiar credenciales
Token sin sub o audienciaScope basic y mapper illari-api del realmRevisar configuración del realm; no reimportar sobrescribiendo usuarios
401Firma/expiración/issuer/audienciaNuevo login válido; no desactivar el resource server
403 en caso o agendaRol real y vínculo local, propietarioVincular/revisar IDs autorizados; agenda general solo ADMIN
404 en orden ajenaPolítica de ocultamientoNo revelar existencia ni ampliar acceso para «arreglar»404
502 o spinnerDNS nginx/Gateway y EurekaResolver dinámicamente y esperar rutas; no confiar solo en la página estática
503 comprandoCatálogo, timeout/circuitoRestaurar catálogo y esperar llamadas HALF_OPEN; mantener la misma clave si resultado incierto
409 con Idempotency-KeySolicitud distinta con la misma claveNo cambiar una compra incierta; consultar resultado original
CANCELACION_PENDIENTEBroker, comandos outbox y resultado de compensaciónRecuperación ADMIN auditada; no editar estados con SQL
Outbox agotadoPublicaciones/errores, broker ya recuperadoMotivo explícito y reintento ADMIN; no borrar la fila
DLT pendienteContrato, coordenadas y causaRevisar/corregir fixture y replay ADMIN; confirmar inbox y ausencia de duplicados
Panel vacíoVentana, consulta y datasourceGenerar actividad real; un ALERTS vacío sano no es fallo, un panel de latencia sin muestras no se presume aprobado
Loki sin logsAlloy, volúmenes de observación y posicionesRevisar solo el proyecto; nunca montar el socket Docker para saltar el diagnóstico
ddl-auto=validate fallaBase/esquema/migracionesInspección+respaldo restaurado antes de autorización; no cambiar a create-drop
Puerto ocupadoCompose port y otros proyectosUsar puertos libres y alinear URLs; no detener otro proyecto
Faltan JAR/dist en ZIPSon generados excluidosEjecutar BUILD-S12 con pruebas antes de construir imágenes
Mockito/loopback falla en sandboxRestricción del entorno de ejecuciónRepetir con permisos de laboratorio; no omitir pruebas ni instrumentación
Sesión expira/refresh rechazadoDisponibilidad Keycloak y sesión remotaVolver al login; tokens no se guardan en disco para mantenerlos vivos

El laboratorio se limita a loopback. Para reanudar servicios existentes usar docker compose ... start --wait; para detener conservando información usar stop. No usar borrado de volúmenes como solución.
