# Sustentación S12

## Introducción

ILLARI LEGAL es un sistema distribuido orientado
a la comercialización de productos y servicios jurídicos.

## Evolución desde Unidad I

Unidad I estableció la base de microservicios,
configuración, registro, Gateway y balanceo.

Unidad II incorpora:

- Seguridad distribuida.
- Resiliencia.
- Comunicación asíncrona.
- Consistencia mediante Saga.
- Observabilidad.
- Integración con Angular.
