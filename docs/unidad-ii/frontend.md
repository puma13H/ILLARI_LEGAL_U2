# Frontend Angular

## Funcionalidades

- Catálogo jurídico.
- Carrito de múltiples productos y servicios.
- Creación de órdenes.
- Consulta de órdenes.
- Consulta de pagos.

## Integración

El frontend consume las API a través del Gateway.

## Seguridad

La autenticación se realiza con Keycloak y JWT.
