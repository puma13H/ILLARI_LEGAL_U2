# Cambios de interfaz de entrega

Referencia principal: la interfaz existente de Illari, conservando sus superficies oscuras, acentos y densidad. Referencias secundarias: guías bundled de color y craft de Refero (contraste, foco visible y formularios). Se reutiliza el diagnóstico y las capturas A; la búsqueda remota Refero no dispone de suscripción en esta sesión. No se presenta como investigación remota nueva.

| Decisión | Fuente | Aplicación |
|---|---|---|
| Mantener los tokens existentes | Producto ya aprobado y alcance del usuario | No rediseñar marca ni flujo de compra |
| Corregir anchura mínima de sidebar y contenido | Capturas A con superposición | Menú adaptable y paneles sin desbordamiento global |
| Texto secundario legible y foco visible | Refero color/craft | Tokens muted/text y outline para teclado |
| Quitar actividad y notificaciones inventadas | Código/API y diagnóstico A | Casos reales con fecha; sin contador fijo |
| Conversaciones por caso | API jurídica existente y permisos | Selector autorizado, errores y bloqueo de doble envío |

La identidad del encabezado muestra el rol, no el identificador de acceso. Las capturas nuevas no contienen contraseñas ni tokens.
